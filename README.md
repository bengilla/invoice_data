# 懒人发票统计

一个简单易用的本地发票管理系统，支持批量解析和管理电子发票。

## 支持格式

- PDF 发票（文字提取）
- 图片发票：PNG / JPG / JPEG / BMP / GIF（OCR识别）

## 主要功能

- 📁 批量上传发票（支持文件夹选择）
- 📊 按月份自动归类，显示统计数据
- 🏢 购买方分类筛选
- 📥 下载月度/全部发票ZIP包
- 🌗 亮色/暗色主题切换
- 🔍 发票预览（iframe方式）
- ⚠️ 重复文件自动检测

## 使用方法

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖：
- FastAPI
- pdfplumber
- rapidocr-onnxruntime
- Pillow

### 2. 启动服务

```bash
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### 3. 访问页面

打开浏览器访问 http://localhost:8000/local

### 4. 上传发票

1. 点击"点击选择文件夹"
2. 选择包含发票文件的文件夹
3. 系统自动解析所有支持格式的文件

### 5. 查看统计

- 顶部显示发票总数、总金额、月份数
- 如果有多个购买方，显示购买方筛选按钮
- 点击月份卡片展开查看该月发票列表

### 6. 下载发票

- 每个月份卡片下方有"下载月度发票原件ZIP"按钮
- 底部有"下载全部发票"按钮
- ZIP文件按月份分文件夹存储

## 重要概念

### 发票解析规则

系统会尝试提取以下信息：

- **日期**：从"2026年01月31日"格式提取
- **购方**：第一个"名称："后的内容
- **销方**：第二个"名称："后的内容
- **金额**：从"小写 ¥123.45"格式提取
- **发票号**：20位数字

### Unicode规范化

某些PDF使用特殊Unicode字符（如Kangxi radicals），系统会自动转换：

- ⽂ → 文（U+2F42 → U+6587）
- ⽉ → 月（U+2F49 → U+6708）
- ⽇ → 日（U+2F47 → U+65E5）

这确保相同公司的发票能正确归类。

### 重复检测

系统通过两种方式检测重复：

1. **文件名重复**：相同文件名的文件会被跳过
2. **内容重复**：相同内容（MD5哈希）的文件会被跳过

重复文件会弹窗提示，不会计入统计数据。

### 会话机制

- 上传的发票文件会临时存储在服务器
- 每次上传生成唯一会话ID
- 关闭浏览器后文件会被清理
- 不同会话之间数据不共享

## 常见问题

### Q: 为什么有些发票解析失败？

A: 可能原因：
- 发票格式不在支持范围内
- 图片质量太低，OCR无法识别
- 发票使用了特殊字体或布局

### Q: 为什么购买方显示"未知"？

A: 发票可能没有标准格式的购买方信息，系统无法提取。

### Q: 下载的ZIP文件在哪里？

A: 浏览器默认下载到"下载"文件夹，文件名格式为"年份-金额总数.zip"。

### Q: 支持哪些浏览器？

A: 推荐使用Chrome、Edge、Firefox等现代浏览器，需要支持ES6+和File API。
